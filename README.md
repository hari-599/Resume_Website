## 🚀 Installation & Local Development

If you want to run this project locally:

1.  **Install the Gatsby CLI**
    ```sh
    npm install -g gatsby-cli
    ```

2.  **Install Dependencies**
    ```sh
    npm install
    # or
    yarn
    ```

3.  **Start the Development Server**
    ```sh
    npm start
    ```

4.  **Build for Production**
    ```sh
    npm run build
    ```
